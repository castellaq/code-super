# 나의 개인 프로필 페이지 🎨

환영합니다! 이것은 나만의 개인 프로필 페이지입니다.

## 🌟 프로젝트 소개

간단한 HTML과 CSS로 만든 아름다운 프로필 페이지입니다.
코딩 초보자도 쉽게 수정하고 자신만의 페이지를 만들 수 있습니다!

## 🚀 시작하기

### 1. 파일 수정하기

`index.html` 파일을 열어서 다음 부분을 수정하세요:

- **이름**: `<h1>당신의 이름</h1>` 부분을 수정
- **자기소개**: `<p class="bio">` 안의 내용을 수정
- **관심사**: 관심사 리스트 항목들을 수정
- **목표**: 목표 리스트 항목들을 수정
- **링크**: GitHub 링크와 이메일을 자신의 것으로 변경

### 2. 로컬에서 보기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 볼 수 있습니다!

### 3. GitHub Pages로 배포하기 (선택사항)

실제 웹사이트로 만들고 싶다면:

1. GitHub에서 이 저장소(repository)로 이동
2. **Settings** 탭 클릭
3. 왼쪽 메뉴에서 **Pages** 클릭
4. **Source**에서 브랜치 선택 (예: `main` 또는 현재 브랜치)
5. **Save** 버튼 클릭
6. 몇 분 후 `https://your-username.github.io/code-super/` 에서 확인!

## 💡 커스터마이징 팁

### 프로필 이미지 바꾸기

이모지 대신 실제 사진을 사용하고 싶다면:

```html
<!-- 기존 코드 -->
<div class="profile-image">👤</div>

<!-- 이렇게 변경 -->
<img src="your-photo.jpg" alt="프로필 사진" class="profile-image">
```

### 색상 바꾸기

`<style>` 태그 안에서 색상 코드를 변경하세요:
- 보라색 그라데이션: `#667eea`, `#764ba2`
- 원하는 색상으로 변경 가능!

### 섹션 추가하기

관심사, 목표 외에도 자유롭게 섹션을 추가할 수 있습니다:
- 좋아하는 음악
- 읽은 책
- 여행 가고 싶은 곳
- 배우고 싶은 것들
